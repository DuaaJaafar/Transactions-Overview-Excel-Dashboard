# 💳 Transactions Overview Dashboard (Excel)

An interactive, executive-level financial transactions dashboard built in *Microsoft Excel*. This project analyzes customer transaction behavior, channel performance, and transaction success rates across different cities.

## 🎯 Key Metrics & KPIs
- *Total Transactions:* 7,520 Transactions
- *Total Transaction Volume:* $5.12B+
- *Success Rate:* 46.66%

---

## 🔍 Core Features & Insights
- *Transaction Status Distribution:* Donut chart showcasing the breakdown between successful and failed transactions.
- *Geographical Breakdown:* Ranked column chart displaying transaction volume across major cities.
- *Payment Card Performance:* Horizontal bar chart comparing sales and volume generated by card providers (Visa, Mastercard, Discover, Amex).
- *Dynamic Interactivity:* Multi-criteria Slicers filtering by Card Type, Status, and City.

---

## 🛠️ Tools & Techniques Used
- *Microsoft Excel*
- *Pivot Tables & Pivot Charts*
- *Custom Slicers & Timeline Formatting*
- *Dashboard UI/UX Principles:* Custom color palettes (Navy & Gold), KPI alignment, and clean visual structure.
