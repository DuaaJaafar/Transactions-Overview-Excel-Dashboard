# 📊 Transactions Overview Dashboard

A professional Excel dashboard built to analyze transaction data, track daily volumes, evaluate success and failure rates, and break down performance by cities and card types.

---

## 🚀 Project Overview
This project focuses on transforming raw financial and transactional data into an interactive, clean, and visually compelling Excel Dashboard. It provides key business insights at a glance, helping stakeholders monitor daily performance and operational metrics effectively.

---

## 🛠️ Tools & Technologies Used
* *Microsoft Excel:* Used for data processing, cleaning, creating Pivot Tables, and designing the dashboard layout.
* *Icons8 / Flaticon:* Used for modern, high-quality PNG icons to enhance UI/UX.
* *GitHub:* Version control and project documentation.

---

## 📈 Key Metrics & Dashboard Sections
1. *Summary Cards (Top Row):*
   * *Avg. Failed Rate & Avg. Success Rate:* Average metrics comparing transaction outcomes.
   * *Top City & Total Transaction Volume:* Highlighting top-performing regions and monetary values.
   * *Total Transactions & Success Rate:* Overall transaction counts and global success percentages.

2. *Visual Charts & Pivot Tables:*
   * *Transactions Status Rate:* A donut chart illustrating the proportion of successful vs. failed transactions.
   * *Transaction & Failure Rate by City:* Bar charts detailing geographic performance.
   * *Sales by Card Type:* Breaking down volume and usage across various payment cards (Amex, Discover, Mastercard, Visa, etc.).
   * *Total Daily Volume:* Line chart capturing the trend of transaction volume over the days of the month.

## 💡 Key Learnings & Features
* Built entirely compatible with *Excel 2013*, utilizing custom image icons and manual formatting to overcome version limitations.
* Clean data modeling using *Pivot Tables* to compute averages and categorize status codes (0 and 1).
* Professional dark-themed UI design optimized for readability and executive presentation.
